# Thẩm mỹ viện Hương Mận

Website HTML tĩnh với giao diện champagne, tối ưu cho PC và điện thoại.

```sh
npm ci
npm run build
npm run check
npm run dev
```

Mở `http://127.0.0.1:8080/` để xem bản build. Chỉ xuất bản thư mục `dist/`.

Xem [hướng dẫn phát triển và SEO](DEVELOPMENT.md) để chỉnh giao diện, nội dung, thông tin liên hệ và cấu hình triển khai. Nguồn chính nằm trong `site/`; các trang HTML được sinh lại bởi `npm run build`.

Website công khai: [thammyhuongman.com](https://thammyhuongman.com).
